GURIPIN ANDROID - MASHRUUCA BILOWGA

Waxa ku jira:
- Android app shell (Java + WebView)
- Shaashad furitaan 5 ilbiriqsi ah
- Khariidad OpenStreetMap oo Muqdisho ku bilaabmaysa
- Menu-ga GuriPin
- Raadinta demo (wali database kuma xirna)
- Codsiga oggolaanshaha GPS

Xaaladda:
Kani waa mashruuca bilowga ah ee Android. APK diyaar ah weli lagama dhisin.
Raadinta guryaha iyo xogta dhabta ah waxay shaqayn doonaan marka Cloudflare Worker lagu xiro D1.

Sida loo dhiso:
1. Ku fur folder-kan Android Studio kombiyuutar leh Android SDK.
2. Sug Gradle Sync.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK-ga waxaa laga helayaa app/build/outputs/apk/debug/app-debug.apk.

Fiiro:
Map tiles waxay u baahan yihiin internet. GPS wuxuu u baahan yahay oggolaansho.
